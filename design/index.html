STATE 01
初始状态
应用启动后的待机界面：磁盘占用环图 71%，可释放空间显示「待扫描」，结果区为空状态提示。
state-01-idle.html
STATE 02
分析中
点击「扫描分析」后：进度条流动、结果逐行出现、扫描光带扫过列表、日志实时滚动输出。
state-02-scanning.html
STATE 03
分析结果
扫描完成：15 个目标全部列出，13 项可清理共 29.53 GB，默认全选，行可展开查看详情。
state-03-results.html
STATE 04
确认清理
点击「执行清理」弹出确认框：待清理清单、合计释放量、高风险项橙色警告条。
state-04-confirm.html
STATE 05
清理中
逐项清理：已完成行打勾置灰并显示释放量，当前行青色脉冲高亮，日志持续输出。
state-05-cleaning.html
STATE 06
清理完成
清理结束：共释放 11.30 GB，环图降至 67%，跳过项保留标记，右下角成功 Toast。
state-06-done.html

◎ 开发实现时请以各状态页为视觉基准：assets/theme.css 定义了全部颜色 / 字号 / 间距 / 动效参数
