# ClearC · C盘清理助手 — 界面原型（状态页版）

`design/` 目录下是一组**按状态拆分的静态界面原型**，作为真实开发（WPF / WinUI / Qt 等）的视觉与交互基准。
高科技暗色主题，纯 HTML/CSS/JS，无需构建，双击任意 HTML 即可在浏览器查看。

> 所有数据均为模拟，不执行任何真实文件操作。

## 文件结构与命名规范

| 文件 | 说明 |
| --- | --- |
| `index.html` | 原型总览导航页（六个状态卡片入口） |
| `state-01-idle.html` | 初始状态：待机、环图 71%、空列表 |
| `state-02-scanning.html` | 分析中：进度条、扫描光带、日志滚动 |
| `state-03-results.html` | 分析结果：15 项列表、默认全选、行详情展开 |
| `state-04-confirm.html` | 确认清理：清单 + 合计释放 + 高风险警告模态框 |
| `state-05-cleaning.html` | 清理中：已完成行置灰打勾、当前行脉冲高亮 |
| `state-06-done.html` | 清理完成：环图 67%、释放 11.30 GB、成功 Toast |
| `assets/theme.css` | 全部样式（颜色 / 字号 / 间距 / 动效的单一来源） |
| `assets/state.js` | 数据与状态渲染器（六个状态页共用，保证一致性） |

命名规则：`state-<两位序号>-<状态名>.html`，序号即真实使用流程顺序。

## 页面骨架（六个状态页完全一致）

```
┌─────────────────────────────────────────┐
│ 标题栏（自绘：logo / 最小化 / 最大化 / 关闭）      │
│ 总览区  磁盘环图 │ 可释放空间大数字 │ 操作按钮+进度 │
│ 筛选栏  分类 chips │ 已选统计 │ 全选              │
│ 结果清单  行 = 勾选框+图标+名称/路径+风险+大小+状态 │
│ 日志视图  时间戳 + INFO/OK/WARN/ERR 分级着色      │
│ 状态栏  状态指示灯 + 系统信息                      │
└─────────────────────────────────────────┘
        （原型专用：底部状态导航条）
```

## 状态流转（按钮已按真实流程联动）

```
01 初始 ──扫描分析──▶ 02 分析中 ──完成──▶ 03 结果 ──执行清理──▶ 04 确认
  ▲                    │ 取消                │重新分析              │开始清理
  │                    ▼                    ▼                      ▼
  └────────────── 01 初始            02 分析中 ←─取消── 05 清理中 ──完成──▶ 06 完成
```

## 开发实现映射（建议 WPF）

| 原型元素 | WPF 实现 |
| --- | --- |
| 自定义窗口 | `WindowStyle=None` + 自绘标题栏，处理拖动 / 双击最大化 / 关闭 |
| 磁盘环图 | 自绘 `Control`（`ArcSegment`）或 `RadialGauge` 控件 |
| 结果清单 | `ListView` + `GridView` 或 `DataGrid`，行模板含勾选框 / 图标 / 两行文本 |
| 行详情展开 | `Expander` 或行下方动态插入详情面板 |
| 日志视图 | 只读 `RichTextBox` / `ListBox`，按级别着色，自动滚动到底 |
| 分类 chips | `ToggleButton` 列表或 `RadioButtons` |
| Toast | 右下角弹出 `Popup` + 动画 |

## 修改演示数据

扫描项（名称 / 路径 / 大小 / 风险 / 可清理性）与各状态配置集中在 `assets/state.js`
顶部的 `ITEMS` 与 `STATES` 对象；视觉参数全部在 `assets/theme.css` 的 `:root` 变量中。
