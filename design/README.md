# ClearC · C盘清理助手 — 交互原型（单窗口版）

`design/index.html` 是**唯一的原型入口**：一个可交互的主窗体，六个状态（待机 → 扫描 → 结果 → 确认 → 清理 → 完成）不再拆分为独立页面，而是全部由界面上的真实操作推进。
科技蓝紫浅色主题，纯 HTML/CSS/JS，无需构建，双击 `index.html` 即可运行。

> 所有数据均为模拟，不执行任何真实文件操作。
>
> **原型即实现参考**：不只是视觉，交互流程（按钮流转、进度动画、勾选联动、右键菜单、取消/重启）也按真实实现的行为编排，开发时可直接对照。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主窗体（唯一入口）：标题栏 / 总览区 / 盘符选择条 / 结果清单 / 日志 / 状态栏 |
| `assets/app.js` | 交互状态机：数据 + 六状态流转 + 扫描/清理动画 + 全部交互逻辑 |
| `assets/theme.css` | 全部样式（颜色 / 字号 / 间距 / 动效的单一来源） |

## 页面骨架

```
┌─────────────────────────────────────────┐
│ 标题栏（自绘：logo / 最小化 / 最大化 / 关闭）      │
│ 总览区  磁盘环图（已选盘合计）│ 可释放大数字 │ 操作按钮   │
│ 盘符条  扫描范围：盘符复选卡（容量条+扫描状态）      │
│ 分组栏  全选 │ 已选统计                          │
│ 结果清单  盘符分区（策略徽标+已选/小计）            │
│           └ 分类分组（组头可折叠 = 数量 + 小计）     │
│             行 = 勾选框+图标+名称/路径+风险+大小     │
│                 + 打开所在目录按钮（右键菜单同款）    │
│ 日志视图  时间戳 + INFO/OK/WARN/ERR 分级着色      │
│ 状态栏  状态指示灯 + 系统信息                      │
└─────────────────────────────────────────┘
```

## 交互流程（在原型里实际点一遍）

```
待机 ──勾选盘符──「扫描分析」──▶ 扫描中 ──自动──▶ 结果 ──「执行清理」──▶ 确认弹窗
 ▲                              │「取消」                  │勾选/右键/打开目录   │「开始清理」
 │                              ▼                        │「重新分析」         ▼
 └──────────────────────── 待机                    扫描中 ◀────────────── 清理中 ──自动──▶ 完成
                                                                        │「取消」│「重新分析」
                                                                        ▼        ▼
                                                                      结果     扫描中
```

| 交互 | 行为 |
| --- | --- |
| 勾选盘符卡 | 待机页可随时增减扫描范围；结果页修改后提示「重新分析」；扫描/清理中锁定 |
| 扫描分析 | 按勾选盘符逐项扫描：进度条、行逐条出现、当前盘「正在扫描」、日志流 |
| 默认勾选 | 扫描完成后自动勾选 C: 低风险项（策略见下表），其余留给用户决策 |
| 勾选结果项 | 实时联动：已选统计、主按钮文字、可释放大数字、各盘「已选」小计 |
| 右键行 / 行尾按钮 | 打开文件（夹）所在目录（日志 + Toast 模拟）、复制路径、勾选切换、展开详情 |
| 执行清理 | 确认弹窗按当前勾选**动态生成**（按盘符分组；含高风险时显示橙色警告） |
| 清理中 | 逐项脉冲高亮 → 打勾置灰显示释放量；环图与「已释放」实时增长；可取消（已完成项保留） |
| 重新分析 | 从结果/完成页再次扫描；环图保留历史清理后的可用空间基准 |
| 最小化 | 窗口收起为底部任务栏胶囊，点击恢复 |
| 关闭 | 退出应用（显示重启层），「重新启动」回到待机并重置全部状态 |

## 勾选与决策策略（真实实现需遵循）

| 场景 | 默认勾选 | 说明 |
| --- | --- | --- |
| C: 低风险项 | ✅ 默认勾选 | 影响不大，如临时文件、各类缓存 |
| C: 中/高风险项 | ❌ 默认不勾选 | 影响较大，如 Windows.old、还原点，由用户决策 |
| 其他盘符全部结果 | ❌ 默认不勾选 | 不了解用户数据，一律交由用户决策 |
| 不可清理项 | 禁用 | 置灰展示，仅提供定位/查看 |

辅助决策：每行提供「打开所在目录」按钮与右键菜单，用户可先查看文件内容再决定是否勾选。

## 开发实现映射（建议 WPF）

| 原型元素 | WPF 实现 |
| --- | --- |
| 自定义窗口 | `WindowStyle=None` + 自绘标题栏，处理拖动 / 双击最大化 / 最小化 / 关闭 |
| 盘符选择条 | `DriveInfo.GetDrives()` 枚举本地盘 → `ItemsControl` + `CheckBox` 卡片模板（容量条自绘） |
| 磁盘环图 | 自绘 `Control`（`ArcSegment`）或 `RadialGauge` 控件（聚合已勾选盘符） |
| 结果清单 | `ListView` + `GridView` 或 `DataGrid`，行模板含勾选框 / 图标 / 两行文本 |
| 状态机 | 与 `app.js` 的 `phase` 一致：`Idle → Scanning → Results → Cleaning → Done`，确认弹窗为模态 |
| 默认勾选策略 | 扫描器输出 `DefaultChecked`：仅 C 盘低风险项为 true，其余 false |
| 打开所在目录 | `Process.Start("explorer.exe", $"/select,\"{path}\"")` |
| 右键菜单 | 行级 `ContextMenu`（打开所在目录 / 复制路径 / 勾选 / 展开详情） |
| 行详情展开 | `Expander` 或行下方动态插入详情面板 |
| 日志视图 | 只读 `RichTextBox` / `ListBox`，按级别着色，自动滚动到底 |
| 分组结构 | 盘符 `ItemsControl`（分区）→ 分类 `ItemsControl`（组）→ 行，组头用 `Expander` |
| Toast | 右下角弹出 `Popup` + 动画 |

## 修改演示数据

盘符（容量 / 类型 / 卷标）集中在 `assets/app.js` 顶部的 `DRIVES`（取自本机实际磁盘）；
扫描项（名称 / 盘符 / 路径 / 大小 / 风险 / 可清理性）在 `ITEMS`；
默认勾选策略见 `defChecked()`（仅 C 盘低风险项自动勾选）；
清理特例（文件占用 → 部分清理）见 `OUTCOMES`；
视觉参数全部在 `assets/theme.css` 的 `:root` 变量中。
