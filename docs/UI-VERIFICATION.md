# ClearC 0.2.12 界面与行为验收

本机基线为 Windows x64、1060 × 700、简体中文与英文；CodeWF.Avalonia 12.1.4.22、CodeWF.Toolkit 1.0.0.19。主界面沿用磁盘总览、结果清单、日志与状态栏的产品结构，标题栏统一使用 Ursa 三态主题按钮、八配色圆点与语言图标菜单，移除重复下拉框。

关于窗口使用 12.1.4.22 的实际模板检查三颗按钮：最小化、最大化按钮可见且禁用，即使直接触发点击事件也不会改变窗口状态；关闭按钮保持可用。

## 可复现命令

```powershell
dotnet test ClearC.slnx -c Release
pwsh scripts/sync_localization_keys.ps1 -Check
pwsh scripts/build_standalone_prototype.ps1 -Check
npm ci --prefix design/tests
# 首次运行需要安装浏览器：在 design/tests 目录执行 npx playwright install chromium。
npm test --prefix design/tests
dotnet run --project scripts/ui-verification/UiVerification.csproj -c Release -- artifacts/ui-managed
node design/tests/compare-layout.cjs artifacts/ui-managed artifacts/prototype-audit
pwsh scripts/publish.ps1 -RuntimeIdentifiers win-x64
```

独立验证器使用 Headless 平台与真实 Skia 渲染，不创建系统窗口，不占用鼠标键盘；正式程序的 `--selfcheck` 默认使用系统窗口平台，锁屏环境应使用独立验证器。NativeAOT 验证器编译及运行命令见 [发布流程](RELEASE.md)。

## 覆盖范围

- 核心及桌面测试共 196 项（中文格式化测试显式指定全局语言，避免英文 CI 默认语言改变预期），包含风险选择、路径约束、清理白名单、Windows 命令解析、日志脱敏、取消与状态流转。
- 原型将唯一 HTML 复制到空目录并阻断外部资源，遍历两语言 × 八配色 × 明暗共 32 组合，检查同窗切语、偏好恢复、六个工作流视图、勾选、右键、取消、确认、日志导出、关于及六种更新状态；禁止脚本错误及英文界面残留中文。
- 应用验证器输出 44 张真实视图 PNG 及对应坐标：32 张外观与语言组合、2 张双语关于窗口、10 张双语扫描／结果／确认／清理／完成状态。
- 验证同一窗口切语后主题、配色和语言选项不丢失，未提权提示随语言更新；检查偏好 JSON 实际落盘、重新加载及系统模式保存。
- 扫描和清理由受控服务驱动实际 ViewModel 与 AXAML；真实目录大小计算仅使用隔离样例目录。更新检查覆盖发现版本、下载、安装与退出请求、失败、最新、检查取消、下载取消及无匹配资产跳转；不下载或执行真实安装器。

宿主 JSON 输出到 I18n，T4 生成强类型键；库文案通过 NuGet 内嵌并共享唯一全局实例。macOS 安装包的宿主翻译从 `Contents/Resources/I18n` 加载。macOS 正式程序与原生离屏验证器使用经典链接器并关闭压缩调试符号，规避 Apple 新链接器的 [largeAddends 断言](https://github.com/dotnet/runtime/issues/119380)；Windows 和 Linux 不启用此设置。

## 原型与实现对照

42 个主窗口及工作流视图分别量测窗口、工作区、磁盘环图、结果列表、日志和状态栏六个区域，共 **1008 个坐标与尺寸值**，容差 2 DIP。本机受控基线中，窗口为 `(0,0,1060,700)`，工作区为 `(1,45,1058,466)`，环图为 `(27,61,132,132)`，日志为 `(1,511,1058,160)`。

这项检查只覆盖列出的区域，不代表整页像素相似率。标题栏外观入口尺寸、环图、Hero 字号与行高、扫描筛选栏和空态裁切已逐项修正；浏览器与 Semi 原生输入控件的边框、字体度量、窗口按钮及动画笔触仍存在差异。原型使用 21 个可交互样例，原生工作流使用 3 个受控任务，不把样例行数和内容差异计作布局缺陷。

## 平台与人工验收边界

Windows x64 正式 NativeAOT 发布成功；正式 EXE 的 `--verify-runtime` 实际运行通过，检查发布目录双语资源、语言切换及隔离偏好保存。独立原生验证器在 CodeWF.Avalonia 12.1.4.22 下重新编译并实际运行成功，退出码 0，生成 44 张 PNG，原生与原型 1008 项坐标对照通过。README 的静态图、六帧工作流动画及本页关于窗口均来自此次最终原生输出。正式 Windows 发布补齐完整反射元数据参数，与原生验证器保持一致。五平台 CI 均原生编译并执行离屏验证器，安装器另行打包并验证 SHA-256。Semi、Ursa 与 Reactive 的裁剪／AOT 分析告警保持可见。

ClearC 的实际扫描、提权和清理只支持 Windows；Linux/macOS 验证器检查 34 张外观及关于视图、偏好、更新和隔离目录计算，跳过仅适用于 Windows 的清理目标与工作流。相应安装包验证构建与分发结构，正式程序在这些平台提示后以退出码 2 结束，不代表已支持跨平台清理。锁屏期间未执行人工桌面验收，多 DPI、跨屏、窗口拖动、文件选择器、管理员重启和实际安装器交互仍需在可用桌面及目标系统验证。

标题栏新增交互验收：实际触发 Ursa 内部按钮完成系统 → 浅色 → 深色 → 系统循环，保持当前 Studio 配色；打开语言图标菜单并执行实际选项，核对唯一全局语言及宿主设置同步。

## 0.2.11 增量复核

复现了两个问题：直接修改唯一全局 `I18nManager.Culture` 时，第三方内建菜单仍保留旧语言；经宿主入口切语时，原合并方式覆盖了宿主同键资源。现改为订阅全局语言变化，通过 Semi／Ursa 主题自己的 `Locale` 更新内建文案。真实输入框同一个复制／粘贴菜单中英回切四次、Ursa 取消文案以及宿主覆盖均在 managed 和 NativeAOT 验证器通过。

本机正式 Windows AOT 发布、正式 EXE `--verify-runtime` 均成功，实际版本为 `0.2.11.0`。独立原生验证器生成 44 张真实 PNG，42 个视图的 1008 项坐标对照通过；本页和 README 截图、六帧工作流 GIF 已更新为此次原生输出。Windows Inno Setup EXE 与 SHA-256 已生成，未执行安装器。196 项测试、T4、原型重建检查均通过；精确安装包门禁新增 13 个受控场景并进入 CI 与 Release，覆盖错产品、额外版本段、缺失／错误校验、空包和多余文件。

随后使用仅从 nuget.org 还原的隔离缓存、独立中间目录重新完成上述正式发布、EXE 自检、原生界面与安装包编译。最终截图及 GIF 来自这次官方包验证，不复用开发缓存中的同版本包。另用临时采集代码在 managed 离屏环境检查 960 × 620 的中英主界面、扫描、结果、确认、清理、完成和日志底部，检查主要操作与滚动入口；这部分不计为新增原生断言。

`v0.2.11` 的七个发布作业均成功，五个平台各有安装包和 SHA-256，共十项资产。已下载校验文件并核对 GitHub 计算的安装包摘要及校验文件自身摘要；没有在本机完整下载跨平台安装包后重新计算摘要，也没有执行安装器。

## 0.2.12 后台全局切语

新增后台直接切换唯一全局语言、同一个语言菜单回切及外观 JSON 落盘回归。外观模型通过界面线程读取主题并刷新选项；释放后忽略已经排队的切语通知，验证配置文件不再变化。
